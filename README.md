# code to generate 4-area RNN model, forked from Low-rank Inference from Neural Trajectories (LINT)

Code for the paper "Extracting computational mechanisms from neural data using low-rank RNNs", accepted at NeurIPS 2022.

Networks are fitted by the scripts in training_scripts (all weights already in models/), and analyzed in the notebooks.


Within notebooks folder, 4Areas.ipynb and 4Areas_batch.ipynb is for testing code

4Areas_batch.py is the code to train ~30 full models.

4Areas_batch_nofb.py is the code to train ~30 variant 1.

4Areas_batchA3.py is the code to train ~30 full variant 2.

4Areas_batchA6.py is the code to train ~30 full variant 3.
